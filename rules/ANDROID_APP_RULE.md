# 📱 TaskPulse AI - Standalone Android Native App Rule & Replication Blueprint

This specification rule defines the exact architecture, data models, on-device speech & NLP engine, and CI/CD build configuration required to recreate a 1-to-1 carbon copy of the TaskPulse AI Native Android Application.

---

## 📐 1. Technology Stack & Build Tools

- **Language**: Kotlin 1.9.22 (JVM 17)
- **Min / Target SDK**: Min SDK 24 (Android 7.0), Target SDK 34 (Android 14)
- **Build System**: Android Gradle Plugin (AGP) 8.3.0 + Gradle 8.4
- **UI Architecture**: ViewBinding, Material Components, RecyclerView, SwipeRefreshLayout
- **Asynchronous Pipeline**: Kotlin Coroutines (`Dispatchers.IO`, `lifecycleScope`)
- **Speech & Audio**: Android Native `SpeechRecognizer` API + Low-level `AudioRecord` PCM WAV Encoder (16kHz Mono)
- **Local Persistence**: Gson JSON Storage in private app storage (`context.filesDir/data/meetings.json` & `tasks.json`)

## ⚡ 3. Mandatory Android Rules & XML Constraints

1. **100% Standalone On-Device Engine Rule**:
   - The app MUST operate 100% locally out of the box without requiring any external server IP!
   - Speech-to-text MUST be performed using native `SpeechRecognizer`.
   - AI Summaries and Action Tasks MUST be generated by `LocalMeetingEngine.kt`.
   - Persistence MUST write directly to `LocalDataManager.kt` (`filesDir/data/meetings.json`).

2. **Strict AAPT2 XML Entity Escaping Rule**:
   - All raw `&` characters in XML layout strings MUST be explicitly escaped as `&amp;` (e.g. `android:text="Stop &amp; Process"`). Failing to escape raw `&` will crash AAPT2 resource linking!

3. **Android Gradle Plugin (AGP) Compatibility Rule**:
   - `build.gradle` MUST use AGP `8.3.0`.
   - `app/build.gradle` MUST use `id 'org.jetbrains.kotlin.android'` (NOT deprecated `kotlin-android`).
   - `allprojects` repositories block MUST NOT be placed inside `build.gradle` when `settings.gradle` enforces `RepositoriesMode.FAIL_ON_PROJECT_REPOS`.

4. **GitHub Actions CI/CD Build Pipeline**:
   - Use `actions/setup-java@v5` (JDK 17) and `gradle/actions/setup-gradle@v3`.
   - Run `gradle assembleDebug --stacktrace` directly.
   - Upload artifact `app/build/outputs/apk/debug/app-debug.apk` as `TaskPulseAI-debug.apk`.
