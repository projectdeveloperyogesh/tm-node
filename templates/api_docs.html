🚀 Quick Start Guide

TaskPulse AI provides a comprehensive set of RESTful APIs for audio recording, speech-to-text transcription, automated meeting summary generation, task extraction, and AI execution audit logging.

Base Server URL:
http://localhost:3000
Android Emulator Base Host:
http://10.0.2.2:3000

🎙️ Recording & Audio Upload APIs

POST /api/android/upload
Recommended for Mobile Apps

Accepts audio file uploads (`.wav`, `.m4a`, `.mp3`) recorded on Android/mobile devices, transcribes speech with Whisper/SpeechService, and extracts meeting executive summary, items discussed, tasks, prompt payload, cURL command, and raw JSON response output.

Input Parameters (Multipart Form-Data):

FieldTypePresenceDescription
fileFile BlobRequiredAudio recording file (.wav, .m4a, .mp3)
meeting_titleStringOptionalTitle of meeting session (Default: "Android Recorded Session")
target_languageStringOptionalTarget language for summary & tasks (Default: "English")
live_transcriptStringOptionalPartial on-device live transcript text (if available)

Executable cURL Request Example:

curl -X POST "http://localhost:3000/api/android/upload" \ -F "file=@meeting_recording.wav" \ -F "meeting_title=Android Mobile Strategy" \ -F "target_language=English" \ -F "live_transcript=Discussed mobile UI updates and release timeline."

Response JSON Format & Output Parameter Descriptions:

{ "status": "success", "meeting": { "id": "m9x2k41b", "title": "Android Mobile Strategy", "language": "English", "created_at": "2026-08-08 19:40:00", "audio_url": "/recordings/web_rec_20260808194000.wav", "audio_filename": "web_rec_20260808194000.wav", "transcript": "Discussed mobile UI updates and release timeline.", "summary": "Meeting Session Overview: Discussed mobile UI updates and release timeline.", "items_discussed": [ { "topic": "Mobile UI", "details": "Updated layout with Play and Delete buttons", "category": "Design" } ], "task_count": 1, "prompt": "Analyze meeting transcript for 'Android Mobile Strategy'...", "curl_command": "curl -X POST \"http://localhost:3005/api/v1/ai/chat\" ...", "response_raw": "{\n \"summary\": \"Meeting Session Overview...\",\n \"tasks\": 1\n}" }, "tasks": [ { "id": "t81a92", "meeting_id": "m9x2k41b", "title": "Release Mobile APK Build", "assignee": "Alex", "priority": "High", "due_date": "Tomorrow", "status": "todo" } ] }
POST /api/record/upload
Audio Recording Upload Alias

Standard recording upload endpoint for browser and client app recordings. Processes audio, transcribes speech, extracts summary and action items.

Executable cURL Request Example:

curl -X POST "http://localhost:3000/api/record/upload" \ -F "file=@audio_session.wav" \ -F "meeting_title=Team Sync Notes" \ -F "target_language=English"

Response JSON Format:

{ "status": "success", "meeting": { "id": "r7k9p2a1", "title": "Team Sync Notes", "language": "English", "created_at": "2026-08-08 19:42:00", "audio_url": "/recordings/web_rec_20260808194200.wav", "transcript": "Transcribed audio content...", "summary": "Meeting Session Overview...", "task_count": 2 }, "tasks": [] }
POST /api/transcribe/text
Direct Text AI Analysis

Directly accepts raw text transcripts without requiring audio files. Runs MeetingAnalyzer to extract executive summary, items discussed, tasks, prompt payload, cURL command, and raw response.

Input Parameters (Form Urlencoded / JSON):

FieldTypePresenceDescription
textStringRequiredRaw transcript text content to analyze
meeting_titleStringOptionalTitle of meeting session (Default: "Text Transcript Session")
target_languageStringOptionalTarget language for output (Default: "English")

Executable cURL Request Example:

curl -X POST "http://localhost:3000/api/transcribe/text" \ -d "text=John will deploy the Node server. Sarah will test the API endpoints." \ -d "meeting_title=Sprint Retro Notes" \ -d "target_language=English"

Response JSON Format:

{ "status": "success", "meeting": { "id": "txt892a1", "title": "Sprint Retro Notes", "language": "English", "created_at": "2026-08-08 19:44:00", "transcript": "John will deploy the Node server. Sarah will test the API endpoints.", "summary": "Meeting Session Overview: John will deploy Node server and Sarah will test API endpoints.", "task_count": 2 }, "tasks": [ { "title": "Deploy Node Server", "assignee": "John", "priority": "High", "status": "todo" }, { "title": "Test API Endpoints", "assignee": "Sarah", "priority": "Medium", "status": "todo" } ] }

🎛️ Server Dual Recording Controls

POST /api/record/start

Starts dual-channel hardware soundcard recording on the host server.

Executable cURL Request Example:

curl -X POST "http://localhost:3000/api/record/start" \ -H "Content-Type: application/json" \ -d '{"meeting_title": "Live Server Session", "target_language": "English"}'

Response JSON Format:

{ "status": "recording", "meeting_title": "Live Server Session", "target_language": "English", "message": "Dual audio soundcard recording started successfully." }
GET /api/record/status

Returns live soundcard volume decibel levels, mic/speaker mute flags, and elapsed recording time.

Executable cURL Request Example:

curl -X GET "http://localhost:3000/api/record/status"

Response JSON Format:

{ "is_recording": true, "is_paused": false, "is_mic_muted": false, "is_speaker_muted": false, "elapsed_seconds": 124, "mic_level": 45, "speaker_level": 60, "live_transcript": [ { "start": "00:05", "speaker": "Mic", "text": "Testing server audio bridge" } ], "current_filename": "server_rec_20260808_194000.wav" }

📋 Meetings & Action Tasks APIs

GET /api/meetings

Returns array of all recorded & analyzed meeting sessions.

Executable cURL Request Example:

curl -X GET "http://localhost:3000/api/meetings"

Response JSON Format:

[ { "id": "m9x2k41b", "title": "Strategy Meeting", "language": "English", "created_at": "2026-08-08 19:40:00", "summary": "Executive Summary...", "task_count": 3 } ]
GET /api/tasks

Returns array of extracted action tasks across all sessions.

Executable cURL Request Example:

curl -X GET "http://localhost:3000/api/tasks"

Response JSON Format:

[ { "id": "t81a92", "meeting_id": "m9x2k41b", "title": "Release Mobile APK Build", "assignee": "Alex", "priority": "High", "due_date": "Tomorrow", "status": "todo" } ]
GET /api/ai/logs

Returns raw AI execution logs including prompts sent, cURL commands, and raw JSON response output.

Executable cURL Request Example:

curl -X GET "http://localhost:3000/api/ai/logs"

Response JSON Format:

[ { "id": "log_101", "timestamp": "2026-08-08 19:40:00", "provider": "Yogesh Chat (Port 3005)", "endpoint": "http://localhost:3005/api/v1/ai/chat", "http_method": "POST", "meeting_title": "Android Mobile Strategy", "prompt": "Analyze meeting transcript...", "curl_command": "curl -X POST \"http://localhost:3005/api/v1/ai/chat\" ...", "response_raw": "{\n \"summary\": \"Overview...\"\n}", "duration_ms": 850, "status": "success" } ]
